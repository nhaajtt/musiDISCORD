musiDISCORD

running 24/7 on a Raspberry Pi 5

A self-hosted Discord music bot that I deploy and run on my own Raspberry Pi 5: from setup, backups, auto-updates and monitoring to a small screen plugged straight onto the GPIO pins to show what is playing. It is small, it plays music all day, and it has never asked for a raise.

S-01

What this project is

Three ideas, one-minute read

A self-hosted music bot

Plays music from my own file library (and SoundCloud), with stats, a music quiz, synced lyrics, and automatic tagging for tracks that lack tags. Written in Node.js and discord.js, streaming through Lavalink.

Runs on real hardware

A Raspberry Pi 5 at home runs the bot 24/7 in Docker, backs itself up every day, updates itself from GitHub (rolling back to the old version if something breaks), is monitored, and can be reached remotely over Tailscale.

Has its own screen

A 3.5-inch touch TFT on the GPIO pins shows the current track like a magazine cover, controlled with a stylus. Getting it to work was the hardest and most time-consuming part of the project.

S-02

Where your data lives

Self-hosted means the data
stays on the bot owner's machine

Stays on the bot's machine

The bot is self-hosted: stats, playlists and ratings live in the data/ folder on the machine of whoever runs the bot, and are not sent to any service of mine.

Nothing goes to third parties

Apart from the two optional lookups already documented on the privacy page (AcoustID and MusicBrainz to identify tracks, LRCLIB for lyrics), the bot sends no data out. It does not read message content.

You can delete it yourself

/privacy delete removes your data, personal playlists included; /privacy stats stops stats being recorded about you.
